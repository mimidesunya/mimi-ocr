自動準備する外部ツール
法匪テンプレートは同梱版を使います。ndlocr-lite は初回使用時に .mimi-tools へ準備します。分割復元は Hugin を使います。ffmpeg は Windows では自動準備し、Mac では Homebrew などで入れたものを使います。

Gemini

  1. Google AI Studio を開きます。
  2. Googleアカウントでログインします。
  3. APIキーのページで「作成」または「Create API key」を押します。
  4. 出てきた長い文字列をコピーして、設定の Gemini APIキーへ貼ります。

OpenAI

  1. OpenAI Platform を開きます。
  2. ログインして、API keys のページへ進みます。
  3. 「Create new secret key」を押します。
  4. 表示されたキーは一度しか見られません。すぐコピーして、設定の OpenAI APIキーへ貼ります。

Claude

  1. Anthropic Console を開きます。
  2. ログインして、API Keys のページへ進みます。
  3. 「Create Key」を押します。
  4. 出てきたキーをコピーして、設定の Claude APIキーへ貼ります。
APIキーは家の鍵のようなものです。SNS、チャット、GitHub、メールに貼らないでください。知らない人に使われると、自分に料金が来ることがあります。
