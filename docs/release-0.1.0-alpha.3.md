# MIMI OCR 0.1.0-alpha.3

Windows alpha の第3版です。初めて使う方向けに設定画面を整理しました。

## 配布物

- `mimi-ocr-win-x64-0.1.0-alpha.3-<timestamp>.zip`

## 主な変更

- 設定画面のAPIキー欄を平文表示に変更し、隠す必要のない情報として扱うようにした
- APIキー欄にクリップボードからの貼り付けボタンを追加
- 設定画面の先頭に「使いたいAIサービスを1つ選んでAPIキーだけ入力すればよい」という案内を追加
- 外部ツール（ndlocr、分割復元、ReazonSpeechなど）の詳細設定を折りたたみ表示にし、初めて開いたときの情報量を減らした
- メインウィンドウの内容が窓の高さに収まらない場合に、要素が見えなくなっていた不具合を修正（スクロール対応、既定の高さを拡大）
- 設定画面を開いている間はウィンドウを一時的に広げ、閉じると元の大きさへ戻すようにした

## 互換性とアップグレード

- `*_paged.md`、`*_ERROR_paged.md`、`*_merged.md` のファイル名とページ境界形式は維持しています。
- 旧版のZIPへ上書きせず、新しいフォルダへ展開して `mimi-ocr.exe` を起動してください。
- APIキーやモデル上書きはGUIの「設定」から確認してください。
- `config.json` に保存済みのAPIキーやモデル指定はそのまま引き継がれます。

## 既知の制限

- この配布物は Windows x64 用です。macOS向け配布物は含みません。
- Gemini / Claude / OpenAI を使う処理には各サービスのAPIキーが必要です。
- `ndlocr-lite` と Reazon K2 の初回準備には外部ネットワーク接続が必要です。
- 裁判資料など重要文書では、証拠番号、日付、固有名詞、ページ境界を原本と照合してください。
