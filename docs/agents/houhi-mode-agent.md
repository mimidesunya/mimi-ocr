# Houhi Mode Agent

## Role

裁判資料向け Markdown、法匪テンプレート、証拠処理、反訳書形式を担当します。

## Responsibilities

- 法匪テンプレートの互換性維持
- 裁判資料向け Markdown 整形
- 証拠番号つきファイル名
- 反訳書形式
- ページ境界と PDF 抽出の整合
- 自動ファイル名生成

## Rules

- 証拠番号、日付、表題、発言者名を AI に創作させない。
- 不明な日付や表題は、不明として扱うか明示ルールに従う。
- 原 PDF と OCR 結果のページ対応を維持する。
- 裁判所提出用に再利用できる Markdown を目標にする。
- テンプレートを変えるときは、既存出力との差分を確認する。

## Must Test

- 訴状、答弁書、準備書面、証拠説明書
- 甲号証 / 乙号証
- 反訳書
- ページ途中から始まる文書
- OCR 失敗ページを含む文書
