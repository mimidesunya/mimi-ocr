# MIMI OCR 0.1.0-alpha.4

Windows alpha の第4版です。音声認識を、長時間音声と公開・提出用の反訳に耐えられる構成へ更新しました。

## 配布物

- `mimi-ocr-win-x64-0.1.0-alpha.4-20260830-210219.zip`

## 主な変更

- Gemini 3.5 Transcribe の `verbatim` モード、話者分離、単語タイムスタンプを使用する専用リクエストに対応
- 話者別・一文別の文字起こしを生成し、元の話者ID、開始・終了時刻、ミリ秒精度の情報を保持
- 長時間音声を10分区間と重複部分に分け、区間の欠落、時刻の逆行、重複接続を検出する処理を追加
- 書き起こし後に全体コンテキストを使って話者名と誤認識を補正する2段階処理を追加
- 文字起こしモデルとは別に補正AIモデルを選択できるようにし、モデル選択UIをコンボボックスへ統一
- 一般モードでは調査用の話者IDと詳細時刻を残し、法匪モードではID列を省略して秒単位の提出用書式を出力
- 旧形式または不完全な音声認識結果を自動判定し、旧結果を退避して再処理するように変更
- OpenAI APIの無効キーやモデルエラーを成功扱いにしていた不具合を修正
- GPT-5系モデルへ未対応の `temperature` を送っていた問題を修正
- APIキー設定画面の「貼り付け」ボタンが動作しない問題を修正

## 互換性とアップグレード

- `*_paged.md`、`*_ERROR_paged.md`、`*_merged.md` のファイル名とページ境界形式は維持しています。
- 音声認識結果の内部スキーマはバージョン3です。旧版の結果は必要に応じて `_旧結果.md` へ退避し、新しい設定で再処理します。
- 旧版のZIPへ上書きせず、新しいフォルダへ展開して `mimi-ocr.exe` を起動してください。
- `config.json` に保存済みのAPIキーやモデル指定は引き継がれます。音声認識の補正AIモデルはGUIで個別に確認できます。

## 既知の制限

- この配布物は Windows x64 用です。macOS向け配布物は含みません。
- Gemini / Claude / OpenAI を使う処理には各サービスのAPIキーが必要です。
- 音質、同時発話、固有名詞によっては話者名や語句の補正に誤りが残るため、公開・裁判所提出前に原音との照合が必要です。
- 外部APIの提供モデルや権限はアカウントごとに異なります。補正AIモデルが利用できない場合は、GUIで利用可能なモデルへ変更してください。
