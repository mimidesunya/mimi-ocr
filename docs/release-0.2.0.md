# MIMI OCR 0.2.0

弁護士でない個人が、少ない費用で、手間なく使えることを目指した版です。OCR の既定の読み方を変えて精度を上げ、AI と手元の OCR の読みを照合する機能、怪しい頁の読み直し、費用の表示、API キーなしで使える無料の道を加えました。ndlocr-lite は PyPI から入るようになり、Python が無い PC でも自動で準備します。

## 配布物

- `mimi-ocr-win-x64-0.2.0-20261126-154643.zip`

## OCR の精度

- 既定の読み方を「AI＋ndlocr参考」にしました。頁の画像を AI に読ませ、手元の ndlocr-lite の読みを誤りを含む参考として添えます。0.1 の既定（ndlocr の文字だけを AI に整形させる）と比べ、判決・準備書面・証拠説明書の14頁（スキャン相当と FAX 相当）で、本文の欠落が 1.58% から 0.72% に、数字の誤りが 120 中 6 から 2 に減りました。FAX 相当の証拠説明書の表では、欠落 9.09% が 0% になりました（`benchmark/results/2026-11-26-ndlocr方式とモデル.md`）。
- 同じ字や句の異常な繰り返し（黒塗りの頁の ■ の暴走など）、AI の断り書き（「断片的なテキストに基づき…」など）、ndlocr の読みと比べて極端に短い・長い頁を見つけ、1頁ずつ読み直します。それでも残った頁はログの `[要確認]` と末尾メタデータの `suspectPages` に出ます。
- 出力の型の既定を「自動」にしました。最初の頁から裁判書面と判断したときだけ法匪の書式で書き起こし、スライドや行政の資料に裁判書面の文を作ることを防ぎます。

## 照合

- AI と ndlocr-lite の読みで、日付・事件番号・号証番号・金額などの数字が食い違った所を、頁画像の切り抜きと並べた `<名前>_照合.html` にまとめます。AI が書き換えた・作った疑いのある所を先に並べます。GUI では処理の終わりに自動で開きます。ndlocr を使う読み方では既定で行い、画像だけで読むときは `--crosscheck` で行えます。

## 費用と無料の道

- 実行の前に費用の目安を、後に実費（入出力トークンと概算ドル）をログと末尾メタデータの `usage` に出します。単価は `app.defaults.json` の `pricing`（基準日つき）で、`config.json` で上書きできます。gemini-3.1-flash-lite で1頁あたり約 0.001 米ドルでした。
- API キーが1つも無いときは、無料の ndlocr-lite だけで読みます（PDF のみ）。GUI は初回にこの設定を選んで案内を出し、キーの無いまま AI の読み方で始めたときは、無料で続けるかを尋ねます。
- 元の PDF に読んだ文字を見えない層として重ねた `<名前>_検索可能.pdf` を作れます（ndlocr のみのときは既定で作る）。
- Gemini の API キーの案内に、無料枠のキーで送った書類は Google が製品の改善に使い、人が読むこともあるので、裁判書類は課金を有効にしたキーで送るよう注意を加えました。

## 音声認識

- Chat API の全体補正が、当事者の役割（原告・被告・控訴人・申立人・相手方など）、号証番号、日付・金額などの数字を変えた発言は、補正せず元の書き起こしを使います。件数と例はログと末尾メタデータの `postprocessGuard` に残ります（長尺の補正が「原告」42か所をすべて「被告」に替えた不具合への対策）。

## 導入

- ndlocr-lite を PyPI（`ndlocr-lite>=2.0,<3`）から専用の venv に入れるようにしました。モデル（約157MB）は初回に `%LOCALAPPDATA%\ndlocr-lite\models\v2` へ取ります。
- PC に Python 3.11 以上が無ければ、uv（0.13.8、配布元の sha256 で検証）を外部ツールの保存先に取り、Python 3.12 を用意します。PATH やレジストリには何も登録しません。
- 前の版で GitHub から取った ndlocr-lite がある場合は、依存パッケージを取り直さずに移ります（古い写しは消さず、ログで知らせます）。
- 設定画面で保存すると、手で書いた `tools.ndlocrLite` の `repoPath`・`pythonPath` が消えていたのを直しました。

## 互換性とアップグレード

- `*_paged.md`、`*_ERROR_paged.md`、`*_merged.md` のファイル名とページ境界の形式は変えていません。新しい出力は `*_照合.html`（食い違いがあるときだけ）と `*_検索可能.pdf`（指定したとき）です。
- 0.1 の読み方は `--ndlocr`（GUI の「ndlocr文字→AI」）で使えます。
- 旧版の ZIP へ上書きせず、新しいフォルダへ展開して `mimi-ocr.exe` を起動してください。`config.json` の API キーやモデル指定は引き継がれます。初回の ndlocr-lite の準備に数分かかります。

## 既知の制限

- この配布物は Windows x64 用です。macOS の uv の経路は試していません。
- OCR の結果は正本ではありません。FAX の画質ではどの設定でも日付の数字を読み違えることがあるので、日付と数字は照合レポートと原本の画像で確かめてください。
- ndlocr-lite 2.0 の表の Markdown は、コマンドラインの画像入力では出ないため使っていません。
- ReazonSpeech K2 は今も PC の Python 3.10 以上が必要です（uv の経路は ndlocr-lite だけ）。
- 単価は変わります。各社の料金ページで確かめ、違っていれば `config.json` の `pricing.models` で直してください。
