# MIMI OCR 0.2.2

OpenAI の話者分離のモデルで、事前コンテキストを渡すと音声認識がエラーで止まる不具合を直した版です。

## 配布物

- `mimi-ocr-win-x64-0.2.2-20261127-144343.zip`

## 音声認識

- 話者分離のモデル（`gpt-4o-transcribe-diarize` など）は `prompt` を受け付けないのに、事前コンテキストを含む `prompt` を付けて送っていたため、文脈を渡すとエラーで止まっていました。話者分離のモデルには `prompt` を送らないようにしました。
- 事前コンテキストは、書き起こしの後の Chat API の補正（全体解析・分割補正）でこれまでどおり使います。話者分離のモデルで文脈を渡したときは、ログにその旨を出します。補正を Off にしている場合は、文脈がどこにも使われないことをログに出します。
- 話者分離でない OpenAI のモデル（`gpt-4o-transcribe` など）には、これまでどおり文脈を付けて送ります。Gemini の `gemini-3.5-transcribe` は、もともと文脈を送っていません。

## 互換性とアップグレード

- 出力のファイル名、ページ境界、末尾メタデータの形式は 0.2.1 と同じです。ndlocr-lite の既定（1.4.0）も変わりません。
- 旧版の ZIP へ上書きせず、新しいフォルダへ展開して `mimi-ocr.exe` を起動してください。`config.json` の API キーやモデル指定は引き継がれます。

## 既知の制限

- この配布物は Windows x64 用です。
- 修正は試験で確かめましたが、本物の OpenAI の API への送信ではまだ試していません。
