# MIMI OCR 0.1.0-alpha.5

Windows alpha の第5版です。ndlocr-lite 2.0.0 に対応し、OCR で日付の年が書き換えられる問題と、AI がページを拒否したときに結果が欠ける問題を直しました。長時間音声の区間の継ぎ目で発言が落ちる不具合も直しています。

## 配布物

- `mimi-ocr-win-x64-0.1.0-alpha.5-20261126-103312.zip`

## OCR

- OCR のプロンプト（PDF・画像、ndlocr-lite の後の整形、Word・PowerPoint など）に実行した日の日付を入れるようにした。日付を知らない gemini-3.8-flash が「令和8年」を未来の年とみなし、`(-- as is)` を付けたり令和6年に書き換えたりしていた。日付を `--context-text` で渡す必要はなくなった
- AI がページを拒否したとき（プロンプトのブロックや SAFETY による停止）、複数ページの要求は1ページずつに分けて送り直し、なお拒否されたページは設定の優先順の次のモデルへ回すようにした（GUI・CLI でモデルを1つ選んでいても続けて試す）。すべてのモデルが拒否したページは ndlocr-lite の結果（`--prefer_pdf_text` なら埋め込みテキスト）を補正なしで採用し、ページ先頭の `<!-- mimi-ocr-fallback: ndlocr-lite; reason=ai-refused -->` と末尾メタデータの `aiRefusedPages` で分かるようにした。これまではそのページが `[ERROR: OCR Failed]` で残っていた
- 文字のないページ（白紙、裏写りだけの面、封筒の裏など）は AI に `(--! 文字なし)` と書かせ、解決済みのページとして扱う。白紙除去でも白紙と数える
- RECITATION で止まった応答の文字は採らず、白紙の根拠にもしない。1ページの要求は同じモデルで最大5回まで送り直す
- `*_ERROR_paged.md` に記録されたページ数が PDF と違うときは、ページがずれるので再開せず、`*_ERROR_paged.stale-<日時>.md` へ退避して最初から OCR する
- バッチモードで多くのファイルを一度に処理すると、メモリが尽きて止まることがあった。同時に処理するファイルを32件まで、読み込み中の入力をヒープ上限の8分の1までに抑えた（`MIMI_OCR_BATCH_FILE_CONCURRENCY`・`MIMI_OCR_BATCH_MEMORY_BUDGET_MB` で変えられる）
- 自動改名に全ページ数・用紙サイズ（名刺・はがき・A3〜B6 など）・今日の日付を渡し、文書の種類に「名刺」を加えた。架空の日付が付いたり、名刺を何枚も綴じた PDF に最初の1枚の名前が付いたりしていた

## ndlocr-lite 2.0.0

- ndlocr-lite 2.0.0（モデル名の変更、依存の追加、Python 3.11 以上が必要）に対応した
- venv の印に requirements.txt の sha256 を記録し、ndlocr-lite を取り直して依存が変わったら入れ直す。これまでは最初に入れたパッケージのままで新しい ndlocr-lite を動かしていた
- 自動取得した 2.0.0 より古い写しは取り直し（失敗したら古い写しを残す）、Python 3.11 より古い venv は作り直す。新しい venv には Python 3.11 以上だけを使う
- 設定で `repoPath` を指定した ndlocr-lite は置き換えず、古ければ警告だけ出す

## 音声認識

- gemini-3.5-transcribe で10分を超える音声を区間に分けたとき、区間の境目をまたぐ発言が落ちることがあった（52分と66分の録音で、いくつかの境目で2〜20秒）。前後の区間を10秒ずつ重ね、両方の区間に単語のない間（150ミリ秒以上）で切り継ぐようにした。切り継いだ時刻は末尾メタデータの `audioChunking.seams` に残る
- FFmpeg 9 で `-filter_complex_script` がなくなり、m4a の書き起こしがすべて失敗していたのを直した
- Gemini の単語時刻がまれに大きく巻き戻る応答は、同じ要求を3回まで送り直す
- どの単語にも話者ラベルがない Gemini の応答は、単一話者の録音として `spk:0` を補う（警告を出す）

## GUI・モデル

- GUI の「バッチサイズ」を、OCR では「1回のページ数」、音声認識では「同時処理数」と表示するようにした（CLI の `--batch_size` と設定の `batchSize` は変わらない）
- Gemini のモデルの選択肢に gemini-3.8-flash を加え、`app.defaults.json` の候補も選択肢に出すようにした
- Gemini の Chat の予備のモデルを gemini-3.8-flash にし、OpenAI は Chat に gpt-6-astra、音声に gpt-transcribe を使うようにした

## 互換性とアップグレード

- `*_paged.md`、`*_ERROR_paged.md`、`*_merged.md` のファイル名とページ境界形式は維持しています。AI に拒否されたページには `mimi-ocr-fallback` の印が付きます。
- ndlocr-lite を使うには Python 3.11 以上が必要になりました。初回の実行時に ndlocr-lite 2.0.0 を取得し、venv のパッケージを入れ直すため、時間がかかります。
- 旧版の ZIP へ上書きせず、新しいフォルダへ展開して `mimi-ocr.exe` を起動してください。
- `config.json` に保存済みの API キーやモデル指定は引き継がれます。

## 既知の制限

- この配布物は Windows x64 用です。macOS 向け配布物は含みません。
- Gemini / Claude / OpenAI を使う処理には各サービスの API キーが必要です。
- OCR の結果は正本ではありません。FAX の画質ではどのモデルでも日付の数字を読み違えることがあるため、日付と数字は原本の画像で確かめてください。AI 補正なしで採用したページ（`mimi-ocr-fallback`）は特に目で確かめてください。
- gemini-3.8-flash は flash-lite より遅く、単価も高くなります。
- 音質、同時発話、固有名詞によっては話者名や語句の補正に誤りが残るため、公開・裁判所提出前に原音との照合が必要です。
